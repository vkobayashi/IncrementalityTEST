# Contributing

Bug reports and focused pull requests are welcome.

1. Create a branch from the default branch.
2. Add or update tests for every behavioral change.
3. Run `devtools::document()`, `devtools::test()`, and `devtools::check()`.
4. Update the vignette or README when public behavior changes.
5. Open a pull request explaining the statistical and software impact.

Please do not include confidential experiment data in issues, examples, or
tests. Use synthetic or fully anonymized data.
